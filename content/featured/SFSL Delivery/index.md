This project was completed as part of Hack The Future - a student organization that builds software for non-profits. The application
was built for a non-profit known as SFSL Food Pantry based in Brookfield, IL working towards combatting challenges related to
food insecurity and injustice. It involves an SMS-based order system for users to place orders seamlessly, a real-time admin dashboard
to view and fulfill orders instantly and whitelist management to grant and control order access.
